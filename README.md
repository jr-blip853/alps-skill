# 🏔️ Alps (Active Learning Personal Supporter)

「わたしのペースでしか進まない学び。」をテーマに、AIを「答えを教える先生」や「作業の代行者」ではなく、学習者の出力を引き出して思考を形にする個人専用伴走者として設計した対話スキル定義です。

Google AI Challenge（はたらく・まなぶ部門）応募アイデア「わたしのペースでしか進まない学び。AIと新時代の力を磨く、個人専用伴走者『Alps』」の公開スキルリポジトリとして、Kate が設計・公開しています。

## 学び方の基本形

1. **資料の共有と習熟レベルに合わせた要約・超訳**
   学習者が学びたい内容について、URL・PDF・資料・画像などを Antigravity（または対応する AI パートナー）に共有すると、学習者の習熟レベルに応じた表現方法で要約・超訳して提示します。この過程で外国語の壁や難解な専門用語の壁をクリアし、興味・関心の腰を折らずに学びに専念できます。
2. **対等な対話を通じた思考の言語化**
   学習者は作成された学習ノート（note）を読み、感想・体験談・疑問・アナロジー（たとえ話）などを自由に会話します。AIパートナーが答えやたとえ話を先回りして押し付けるのではなく、学習者自身の言葉や直感を引き出しながら対話を重ねます。
3. **共有学習資産としてのデータベース化**
   対話で生まれた気づきや試行錯誤の過程も含めてその学習者ならではの学習資産としてまとめ、学習完了とともにデータベース化し、学習者と Antigravity の共有学習資産として保存します。

## 3つの設計原則

1. **学習者の出力を引き出す対話**
   AIパートナーが答えを先回りせず、小さな問いかけを通じて学習者自身の経験談や手書き図・言葉を引き出します。
2. **脱線・寄り道の歓迎と歩幅の尊重**
   疑問が湧いたときはカリキュラムを一時停止し、本人が納得するまで自分のペースで議論や寄り道を続けます。
3. **思考と失敗の結晶化**
   対話の中で生まれた気づきや失敗からの学びが流れて消えないよう、その場で構造化して「一生モノの学習ノート」へ資産化します。

## リポジトリ構成

- `skills/alps/SKILL.md`: スキル定義本体（Antigravity Skills 形式。汎用プロンプトとして他AIツールのシステム指示や Gemini Gems 等へも移植可能）
- `docs/CONCEPT.md`: 設計の思想的背景（AI時代における能力のパラダイムシフトと第3の道）
- `LICENSE`: MIT License（Copyright (c) 2026 Kate）

## 使い方

### 1. Antigravity のスキルとして使う
`skills/alps/SKILL.md` を、お使いの環境のスキル配置ディレクトリ（例：`~/.gemini/config/skills/alps/SKILL.md`）へコピーします。チャットで「Alpsで学ぼう」「Alpsスタイルで進めて」と指示すると対話サイクルが起動します。

### 2. Gemini Gems や他の AI チャットで使う
`skills/alps/SKILL.md` の内容（YAMLフロントマターを除いた本文）をカスタム指示（System Instructions）欄に貼り付けるだけで、同じ対話の作法で学習伴走者として動作します。
